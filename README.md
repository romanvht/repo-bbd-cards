# BBD Cards

Мод для R.E.P.O., который добавляет коллекционные карточки в список ценных предметов.

[https://thunderstore.io/c/repo/p/romanvht/BbdCards/](https://thunderstore.io/c/repo/p/romanvht/BbdCards/)

## Установка

Нужны R.E.P.O., BepInEx 5 и REPOLib 4.2.0.

Импортируйте `BbdCards-*.zip` в менеджере модов или скопируйте `BbdCards.dll`
в папку `BepInEx/plugins` игрового профиля.

## Настройки в игре

После первого запуска появится файл `BepInEx/config/romanvht.BbdCards.cfg`.
В разделе `Cards` можно изменить стоимость, массу и хрупкость всех карточек:

| Настройка | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `ValueMin` | 350 | Минимальная базовая стоимость |
| `ValueMax` | 850 | Максимальная базовая стоимость |
| `Mass` | 0.25 | Масса |
| `Fragility` | 20 | Хрупкость от 0 до 100 |

После изменения настроек перезапустите игру.

Для проверки включите `Debug → EnableSpawnKey`. Хост сможет нажимать **F9** во время уровня,
чтобы по очереди создавать карточки перед собой.

## Добавление своих карточек

1. Подготовьте квадратный непрозрачный PNG. Рекомендуемый размер - 512×512, максимальный - 2048×2048.
2. Положите файл в `assets/cards`, например `assets/cards/my_card.png`.
3. Пересоберите мод и установите полученную DLL или ZIP.

В имени используйте латинские буквы, цифры, `_` и `-`. Имена должны быть уникальными
без учёта регистра;

Чтобы заменить карточку, замените её PNG; чтобы убрать - удалите PNG и пересоберите мод.

## Сборка из исходников

Нужны .NET SDK 9, PowerShell, установленная игра и профиль с BepInEx и REPOLib.
Откройте PowerShell в папке проекта и укажите пути к игре и профилю:

```powershell
.\scripts\build.ps1 `
    -GameDir 'D:\SteamLibrary\steamapps\common\REPO' `
    -ProfileDir 'C:\path\to\profile'
```

При первой сборке скрипт копирует необходимые библиотеки из профиля в `.deps`.
Чтобы повторно использовать их:

```powershell
.\scripts\build.ps1 -GameDir 'D:\SteamLibrary\steamapps\common\REPO' -UseLocalDependencies
```

Готовые `BbdCards.dll` и `BbdCards-*.zip` появятся в `dist`.
Ключ `-NoPackage` пропускает создание ZIP.

## Проверка кода

```powershell
dotnet run --project tests/GeometryChecks.csproj
```

Проверка контролирует форму и толщину карточки, треугольники и ориентацию изображения на обороте.
