# BBD Cards

Коллекционные карточки как ценные предметы в R.E.P.O.

[Скачать на Thunderstore](https://thunderstore.io/c/repo/p/romanvht/BbdCards/)

## Установка

Зависимости: BepInEx 5 и REPOLib 4.2.0.

Импортируйте `BbdCards-*.zip` в менеджер модов или скопируйте `BbdCards.dll` в `BepInEx/plugins` профиля.

## Настройки

Конфиг: `BepInEx/config/romanvht.BbdCards.cfg`, создаётся при первом запуске.
Раздел `Cards` задаёт общие параметры для всех карточек:

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| `ValueMin` | 700 | Минимальная базовая стоимость |
| `ValueMax` | 1400 | Максимальная базовая стоимость |
| `Mass` | 0.25 | Масса |
| `Fragility` | 35 | Хрупкость от 0 до 100 |

После изменения настроек перезапустите игру.

Для тестового спавна включите `Debug → EnableSpawnKey`: **F9** по очереди создаёт карточки перед хостом во время уровня.

## Добавление своих карточек

Положите квадратный непрозрачный PNG в `assets/cards` (например, `my_card.png`), пересоберите мод и установите его.
Рекомендуемый размер - 512×512, максимальный - 2048×2048.

В имени файла допустимы латинские буквы, цифры, `_` и `-`. Имена должны быть уникальными без учёта регистра.

После замены или удаления PNG тоже нужна пересборка.

## Сборка

Нужны .NET SDK 9, PowerShell, установленная игра и профиль с BepInEx и REPOLib.

Из папки проекта:

```powershell
.\scripts\build.ps1 `
    -GameDir 'D:\SteamLibrary\steamapps\common\REPO' `
    -ProfileDir 'C:\path\to\profile'
```

Результат - `dist/BbdCards.dll` и `dist/BbdCards-*.zip`.
При повторной сборке можно заменить `-ProfileDir` на `-UseLocalDependencies`, чтобы использовать библиотеки из `.deps`.
`-NoPackage` пропускает создание ZIP.

## Проверки

```powershell
dotnet run --project tests/GeometryChecks.csproj
```

Тесты геометрии карточки и ориентации изображения на обороте.
